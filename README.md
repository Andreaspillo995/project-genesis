# PROJECT GENESIS — 0.4 L’Evoluzione

Web app mobile-first, senza dipendenze esterne, gratuita e pensata per iPhone / GitHub Pages.

## Nuovo nella 0.4

- Genoma ereditabile di quattro geni: metabolismo/efficienza, percezione, agilità, resistenza.
- Ogni nascita combina gli attributi dei due genitori; piccole variazioni e mutazioni deterministiche.
- I tratti hanno conseguenze su fame, sete, clima, movimenti, ricerca risorse e caccia.
- Selezione naturale emergente, genealogia e generazioni; mutazioni stabili / naturali / rapide.
- Grafico delle caratteristiche delle popolazioni; statistiche sulle linee familiari.
- Velocità aggiuntive 16× e 32× per esplorare molte generazioni.
- Salvataggi v4 e importazione v1-v3, mantenendo seme, terreno e dati della 0.3.

## Pubblicazione da iPhone

1. In Safari aprire il repository GitHub `project-genesis`.
2. Estrarre lo ZIP dall'app File. Sostituire i file nella radice di `main`.
3. In GitHub `Settings > Pages`: impostare `Deploy from a branch > main > /(root)` se non è già attivo.
4. Aprire `https://USERNAME.github.io/project-genesis/` (sostituire USERNAME con quello reale). Non aprire l'URL del repository.
5. Prima del primo aggiornamento, esportare sempre un backup .json dalla versione precedente.

## Test veloci

- Tocca creatura: 4 geni e genealogia.
- Laboratorio > Evoluzione > Rapide, velocità 32×: osserva nascite, mutazioni e grafico.
- Esporta backup JSON; reimporta e verifica che popolazione e grafico siano conservati.
- Metti in pausa, chiudi e riapri; salva e verifica il giorno.

Nota: la simulazione gira soltanto quando l'app è attiva sullo schermo.
